## 1. 总原则

| 原则 | 来源 | 落点 |
|---|---|---|
| 视频提示词结构 = 画幅/任务 → 素材职责 → 连续性锁定 → 逐镜（运镜→动作→位置→环境→声音）→ 光线/风格 → 输出限制 | 知识库 `00_使用说明…` §1、`10_Seedance与H3…` §1.2 | `prompts.ts` `videoPrompt()` |

## 2. 拆解（analyze）

- 景别/运镜给**封闭白名单**（`SHOT_TYPES` / `CAMERA_MOVES`），避免「大特写式的中景」这类混合词；
- 新增 `lighting`（光线方向/色温/明暗）与 `environment`（环境动态）两个字段，
  直接喂给下游首帧与视频提示词；
- 要求「主体在画面左/中/右 + 朝向/视线 + 一个主动作」，为跨镜承接提供事实。

## 3. 仿写（rewrite）

- 每个分镜必须给 `shotType` / `camera`，并由 host 端再做一次白名单归一化，
  缺失时回退到源片同序号镜头（`normalizeSegmentLook`）；
- `visualPrompt` 固定顺序：景别 → 主体位置 → 一个主动作（起点→终点）→ 环境动态 → 光线，≤60 字；
- 台词单句 ≤15 汉字、≤ duration×4.5，给听/反应/呼吸留时间；
- 明确禁止互相抵消的约束（固定机位 + 推镜、电影感 + 纪实手持、胶片感 + 4K）。

## 4. 参考图 / 首帧（framePrompt）

按知识库「首帧生成」模板：

```
为镜头 SHxx 生成一张适合「图生视频」的首帧（画幅）
[构图] 景别 + 运镜意图 + 画面内容
[起始姿态] 只表现动作开始前的清晰状态，不要把后续动作提前画出来
[素材] 图片1 = 产品外观锚定（视觉身份证逐字）
[光线] 全片光线基准
[环境动态]
[画面] 前景/中景/背景分层；下方留干净区域便于后期字幕
[输出限制] 单张静帧；无文字/Logo/水印
```

## 5. 分镜视频（videoPrompt）

```
【画幅】竖屏 9:16（720×1280），约 N 秒
【任务】参考图生视频：图片1=产品身份锚定；图片2=起始帧；镜头间硬切
[CONTINUITY_LOCK]
产品：<逐字外观>（与图片1完全一致；只改位置/角度/手持状态）
光线基准：<全片光向与色温>
空间：保持图片2的空间结构与背景固定元素
[/CONTINUITY_LOCK]
镜头1：特写固定，主体在画面右侧，抬手举杯一次 环境动态：… 光线：… 配音说道{台词}
镜头2：…
【风格】…
【输出】画面干净、单镜一动作、无文字/字幕/水印…
```

续写块（第 2 段起）用知识库的「续拍」模板：保留上一段的主体位置/视线/光向/镜头朝向，
前 0.5 秒延续运动方向与节奏，不重新建立场景。

## 6. 已知取舍

- **不用时间戳**：Seedance 2.0 对精确秒数支持不稳，按镜头序号推进更稳；
- **不追求 L4「资产台账」**：插件是「单条片子」场景，产品锁定块 = 简化的角色锁定块；
- **不做镜头级质检**：知识库的「生成后检查」需要视觉复核，当前版本留给人工在界面上看片重生成；
- 抖音竖屏爆款的「0–2 秒钩子」结构只对仿写生效，不强行改写用户的源片结构（复刻优先）。

## 成片质量的五条硬规则（实测踩过坑后加的）

| 规则 | 为什么 |
|---|---|
| **一镜一段** | 把 2 个分镜塞进一条 12 秒视频时，Seedance 只会拍第一个镜头，第二个直接丢失（实测）。`MAX_SHOTS_PER_CHUNK = 1` |
| **双关必须落成物件** | 只写「画饼」，模型画的是白板写字；写成「白板上画着一个巨大的圆形披萨状饼图」才真的出现饼 |
| **动作必须对上台词** | 台词说「再生成一个」时，画面必须是打字/输入，不是扶额叹气 |
| **情绪逐镜升级** | `emotion` 字段从「期待 → 疑惑 → 无语 → 崩溃 → 气急败坏 → 认命」，同时驱动 TTS 语气 |
| **字幕按语音时长切** | 一条字幕挂满 8 秒会显得卡住；按句切分并压到「实际说完」的时间窗内 |

## 配音情绪

MiMo 一类 TTS 用**自然语言风格指令**控制情绪：

```
短视频博主现场吐槽的语气，口语化，不要播音腔；
情绪按顺序升级：期待、疑惑、无语、崩溃、气急败坏、认命；
语速偏快，有明显呼吸和情绪起伏，到崩溃处可以破音、咬牙、叹气
```

chat-tts 协议把它放在 `messages[0]`（用户消息），openai-tts 协议放在 `instruction` 字段。

## 角色与音色（多声线）

分镜带 `speaker` 字段（柴犬/老板/同事…），配音按说话人分音色：

- `tts.voice`：主角（第一位出场的角色）
- `tts.voiceAlt`：其它角色（老板、同事…）；留空则同一音色
- 实测可选音色：`mimo_default, 冰糖, 茉莉, 苏打, 白桦, Mia, Chloe, Milo, Dean`
- 台词必须归给**画面里说话的人**，不能出现「画面是老板、台词却是柴犬」的错位
- 环境音用**侧链闪避**压在配音下面（说话时自动让路），避免和 TTS 叠成双人声
